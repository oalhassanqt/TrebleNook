# TrebleNook

TrebleNook leverages a decentralized, edge-based architecture, utilizing containerized microservices routing and real-time streaming-data processing within a robust Engine.

TrebleNook is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/TrebleNook.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
